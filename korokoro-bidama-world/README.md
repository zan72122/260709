# ころころ びーだまワールド

Marble World 風のビー玉レース物理サンドボックス 3D ゲーム。
空に浮かぶ小島に組まれたコースへ、ボタンひとつでビー玉をどんどん注いで、
らせん塔・ループ・じょうご・シロホン階段・バンパー・スピナー・ブーストリング
をころころ流れていくのを眺めて遊びます。

4歳児(文字が読めない前提)が iPhone / iPad の Safari で、縦画面でも
横画面でも遊べるように作っています。失敗も時間制限もなく、どこをさわっても
何かが光って鳴ります。

## あそびかた

- タイトルで **すきなコースのカード** をタップ
- **🔮 ころころ!ボタン** … タップで1こ、**押しっぱなしでどんどん** ビー玉が流れます
- **🎉 ボタン** … 10こまとめてざーっと注ぎます
- **👀 ボタン** … カメラがビー玉を追いかける「おいかけモード」
- **ゆびでドラッグ** … ぐるっと見まわす / **2本ゆびでピンチ** … ズーム
- **ビー玉をタップ** … ぴょこんとはねる
- **スピナーをタップ** … ぶんぶん加速 / **シロホンをタップ** … 音が鳴る
- ゴールのプールにたまると 🔮 カウント、10こごとに ⭐ + 紙ふぶきのお祝い
- 迷子になったビー玉は キラキラ✨ とワープしてスタートに戻るので、流れは止まりません

### 起動

```
cd korokoro-bidama-world
python3 -m http.server 8000
# → http://localhost:8000 を Safari / Chrome で開く
```

ビルド不要・外部アセットなし(Three.js r160 は vendor/ に同梱、音はすべて WebAudio 合成)。

### テスト

```
npm test
```

- `test/physics-test.mjs` … レール滑走・じょうご排出・OBB 静止・玉同士の反発などの数値検証
- `test/course-test.mjs` … 3コースをヘッドレスで 80 秒シミュレートし、注いだビー玉の
  75% 以上がゴールに到達すること・NaN や場外が出ないことを検証

## こだわりの描写と物理

- **自作ビー玉物理** (`src/physics.js`) — レールは「2本のワイヤー(カプセル鎖)」で表現し、
  溝にビー玉が自然に乗る本物のマーブルラン構造。じょうごは円錐の解析衝突
  (穴の縁はリング接触)、ほかに OBB / 円柱 / ボウル / 回転スピナーの解析コライダー、
  玉同士は空間ハッシュで最大 150 個を 120Hz(高速時は 240Hz に自動細分)で安定計算
- **ホッパー詰まり対策** — 静止アーチだけを崩す微撹拌で、じょうごが決して詰まらない
- **レール生成** (`src/track.js`) — Catmull-Rom 曲線を平行移動フレームでサンプリングし、
  曲率から自動バンク・自動ガードレール・ループ天井レール(端はフレア)を生成。
  枕木と支柱も自動配置
- **ルック** — PMREM 環境マップによる飴玉の映り込み、クリアコートの艶やかなハイライト、
  ソフトシャドウ、グラデーション空ドーム + 太陽グロー + 流れる雲、浮遊する小島、
  コースごとの完全パレット替え(昼空 / 夕焼け / お菓子)
- **エフェクト** — スパークル・紙ふぶき・ギミック発光パルス・高速玉の流れ星トレイル
- **音** — 五音音階のシロホン、玉同士のカチッ、ボヨン、ワープのグリッサンド、
  オルゴール BGM をすべて WebAudio で合成

## ファイル構成

```
korokoro-bidama-world/
├── index.html        UI / HUD / タイトル画面
├── src/
│   ├── main.js       ループ・イベント配線・タップ処理
│   ├── physics.js    ビー玉物理(ヘッドレス動作)
│   ├── track.js      レール生成(スパイン・バンク・ガード)
│   ├── pieces.js     ギミック(じょうご・シロホン・バンパー・スピナー…)
│   ├── courses.js    3コースの定義と装飾
│   ├── environment.js 空・雲・浮島・光・環境マップ
│   ├── marbles.js    インスタンス描画と転がり回転
│   ├── effects.js    スパークル・紙ふぶき・パルス
│   ├── audio.js      WebAudio 合成
│   └── camera.js     タッチオービット / 追跡カメラ
├── test/             ヘッドレス検証
└── vendor/           three.module.min.js (r160)
```
