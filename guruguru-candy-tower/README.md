# 🍭 ぐるぐるキャンディタワー (guruguru-candy-tower)

お菓子工場の**回転するケーキタワー**を、キャンディ玉が約5周かけて旅する
Automatoys風 3Dからくりゲーム。**14のギミック**(操作9+自動5)をフル装備。
4歳児が iPhone / iPad(縦・横どちらでも)で遊ぶことを想定しています。

カメラは玉を追って自動で塔を周回し、**常に見せ場が正面**に来ます。
なにもない所を**スワイプすると自分でも塔をぐるぐる回せます**(離すと自動追尾に復帰)。
衝突やギミックが鳴るたびに**「きらきらぼし」がオルゴールで1音ずつ進み**、遊ぶだけで曲が完成します。

- クリア2回目 🍫 チョコがけとクッキー → 玉が**3個**に
- クリア3回目 🕯️ ロウソクに火が灯って**ケーキ完成の大お祝い**
- 玉同士は物理でぶつかってコツン♪ 複数玉の追いかけっこが楽しい
- 落ちた玉・詰まった玉は自動でガチャグローブへ戻ります

## 実行方法

```bash
cd guruguru-candy-tower
npm start        # python3 -m http.server 8000
# → http://localhost:8000 を iPhone/iPad の Safari か PC ブラウザで開く
```

外部CDN・外部アセットは一切使いません(Three.js はローカル同梱、テクスチャ・音はすべてコード生成)。
`?fast=1` を付けると影とAAを切った軽量描画になります(自動テスト用)。

## テスト


- `test/wrap.test.mjs` — 円筒ラップ座標変換(方位・接線・弦誤差)
- `test/layout.test.mjs` — 14ギミックの接続整合性(受け渡し位置・クリアランス・落差)
- `test/physics.test.mjs` — 平面物理+玉同士の衝突・分離
- `test/melody.test.mjs` — きらきらぼしメロディの検証
- `test/smoke.mjs` — 全モジュールの構文チェックと import

さらに開発時は Playwright + ヘッドレス Chromium で、
クレーン→シーソー→風車→リフト→フリッパー→チューブ→ターンテーブル→ハンマー→
ループ→ドミノゲート→大砲→頂上ケーキ、の**全行程とループ経路を実プレイして検証**しています。

## 技術メモ — 回転塔の作り方

**「平面物理 × 円筒ラップ描画」方式。**
物理は前作 korokoro-karakuri で実証済みの平面エンジン
(x=塔の周方向の弧長, y=高さ, z=半径オフセット)でそのまま解き、
描画だけを `wrap.js` で半径 R0 の円筒に巻き付けます。
カメラが玉の方位角を追って塔の周りを回るため、
「塔が回っている」ように見えます(スワイプはカメラ方位へ介入)。

- Three.js r160 同梱+自作球物理(240Hz固定サブステップ、玉同士の衝突対応)
- レールは短い直線チャンネルの連鎖(物理は平面の直線、描画は接線向きに配置)
- 確実性が要る受け渡し(風車・フリッパー・ターンテーブル・ハンマー・
  チューブ・ループ・大砲)は「捕捉→曲線ライド」のハイブリッド
- ビスケット・スポンジ・アイシング・渦巻き飴・ギンガムチェック、全てCanvasプロシージャル生成
- WebAudio 全生成: オルゴール音色(基音+3.03倍+5.92倍の櫛歯)、
  クリームの絞り音、ハンマーのWHACK、打ち上げのポン!など

## 構成

```
guruguru-candy-tower/
├── index.html        # UI(タイトル・HUD・ケーキ進捗・ふきだし)
├── src/
│   ├── wrap.js       # 円筒ラップ座標系(純関数、テスト対象)
│   ├── layout.js     # 全14ギミックの配置(純データ、テスト対象)
│   ├── physics.js    # 自作物理エンジン(複数玉対応)
│   ├── materials.js  # お菓子素材のプロシージャル生成
│   ├── tower.js      # ケーキ塔・螺旋レール・頂上デコ
│   ├── gimmicks.js   # 14のからくり
│   ├── balls.js      # キャンディ玉(3フレーバー)
│   ├── guide.js      # 3Dの手のガイド
│   ├── audio.js      # オルゴール音楽エンジン
│   ├── particles.js  # スプリンクル紙吹雪・クリームはね
│   ├── camera.js     # 周回追尾カメラ+スワイプ
│   ├── input.js      # タップ/長押し/スワイプ
│   ├── ui.js         # DOM UI
│   └── main.js       # 統合・ゲームループ
├── vendor/three.module.min.js
└── test/
```
