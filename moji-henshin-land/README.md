# もじへんしんランド 🔤✨

Metamorphabet風のインタラクティブABCゲームです。
A・B・C・D・E の5文字を「つつく」「引っぱる」「回す」と、**文字の形そのものが**
段階的に変身していきます。英語が好きな4歳児向けです。

## 文字の形が、そのまま変身する

| 文字 | 変身 | 形の活かし方 |
| :-: | :-- | :-- |
| A | ✈️ Airplane | とがった頂点=機首、ハの字の脚=翼、横棒=折り目、三角の穴=窓。Aは上から見た紙飛行機そのもの |
| B | 🦋 Butterfly | ふたこぶ=羽、ふたつの穴=羽の目玉模様、縦棒=胴体。鏡写しに左の羽が開く |
| C | 🍪 Cookie | 欠け=かじりあと。欠けが閉じてまんまるクッキーになり、最後にまた同じ場所をガブッとかじられてCに戻る |
| D | 🦕 Dinosaur | 横に倒すと平らな底+アーチの背中。カーブに沿って背板が生え、首としっぽが伸びる |
| E | 🐘 Elephant | 横に倒すと背骨+3本の腕。いちばん前の腕がにゅ〜っと伸びて鼻になり、残りが足になる |

## あそびかた

1. すきな文字をタップしてえらぶ
2. 👆 **つつく**(3回)…… 文字が傾き、色が変わり、目や模様が現れる
3. ✋ **引っぱる**(ぐーんと2回)…… 鼻や羽やしっぽが にゅ〜っと生えてくる
4. 🔄 **回す**(くるくる)…… 完全変身! 飛んだり、ドスンドスンしたり、パオーンしたり 🌟

文字は最後まで画面から消えません。変身後も文字のシルエットが体に残るので、
「この文字だから、これに変身した」ことが4歳児にも伝わります。
ゆびのアイコンがヒントとして表示されるので、文字が読めなくても遊べます。

## 動かしかた

ビルド不要です。フォルダごと静的Webサーバーに置いて `index.html` を開くだけで動きます。

```bash
cd moji-henshin-land
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

- 対象: iPhone / iPad の Safari(縦画面・横画面どちらも対応)
- ネット接続不要(Three.js は `vendor/` に同梱、効果音は WebAudio で合成)
- 進捗(できた文字の⭐)は端末内の localStorage に保存されます

## 構成

```
moji-henshin-land/
├── index.html        画面・UI・スタイル
├── src/
│   ├── main.js       ゲーム進行・入力・ばね物理・カメラ
│   ├── letters.js    A〜E の立体文字(フォント不要のShape押し出し+形状座標系)
│   ├── transforms.js 文字ごとの変身コントローラ(段階累積式)
│   ├── anim.js       トゥイーンエンジン
│   ├── fx.js         キラキラ・紙ふぶきエフェクト
│   └── audio.js      WebAudio合成の効果音(ぽよん・ガブッ・ドスン・パオーン等)
└── vendor/
    └── three.module.min.js   Three.js r170
```
