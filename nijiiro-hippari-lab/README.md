# 🧵 にじいろ ひっぱりもようラボ

4歳児向けの **ストリングアート 3D 実験ゲーム** です。
「一本一本はまっすぐな糸なのに、たくさん張ると曲線や花のような模様が見えてくる」——
その数学的な美しさを、**育つ模様・染みる色・動くしずく・光る糸** として遊べます。

iPhone / iPad の縦画面・横画面のどちらでも遊べます(PCブラウザでも動きます)。

## 遊びかた

1. `はじめる ▶` をタップ(効果音とオルゴールが鳴ります)
2. **🧵 いと** … 金色のピンからピンへ指でひっぱると糸が張れる(タップ→タップでもOK)。張った糸は「ぴん♪」と鳴ってふるえる。糸をつまびいてハープあそびもできる
3. **✨ おまかせ** … 1本ずつ自動で糸が増えて、直線だけから カージオイド や星形の曲線が「そだつ」。完成すると包絡線がきらきら浮かび上がる
4. **💨 きりふき** … 糸が濡れてきらめき、小さな水のつぶがつく。つぶが集まると大きなしずくになって転がりだす
5. **💧 いろみず** … 糸に色水をたらすと、しずくが糸を伝って転がり、交点で「ぷるっ」と止まって色がにじむ。にじみは板に残り、模様が育つ。しずく同士は合体し、交差する糸へ乗り移ることも
6. **🔦 ひかり** … 指で光を当てると、濡れた糸としずくが虹色にきらめく
7. **✂️ はさみ** … 糸を切ると模様がふっと変わり、ついていたしずくが落ちる
8. **📷 カード** … できた模様をポラロイド風カードに保存(🖼️ まどかざりギャラリーに残る)
9. かたち(⭕まる・🌸おはな・🌈おうぎ・🟨しかく・💗ハート)を変えてピンの並びをきりかえ、🫧で板をあらう

勝ち負けはなく、「いとを5ほん はってみよう」のようなゆるい *おたのしみ* が順番に出て、達成すると虹ふぶきでお祝いされます。

## 動かしかた

ビルド済みの `dist/game.js` を同梱しているので、静的サーバーで配信するだけで動きます:

```bash
cd nijiiro-hippari-lab
python3 -m http.server 8080
# → http://localhost:8080 をブラウザで開く
```

(`file://` 直開きは不可。モジュールではなく単一バンドルですが、テクスチャ生成等のため http 配信を推奨)

## 開発

```bash
npm install     # three.js + esbuild
npm run build   # src/ → dist/game.js
```

| ファイル | 役割 |
|---|---|
| `src/main.js` | 入力・メインループ・各システムの接続 |
| `src/scene3d.js` | 窓辺のアトリエ背景・木の板・光・ガーランド・ほこり |
| `src/pins.js` | ピン配置(まる/おはな/おうぎ/しかく/ハート) |
| `src/threads.js` | 糸:張り・たわみ・振動・濡れ・にじみ・交点計算 |
| `src/drops.js` | しずく物理:糸を伝う・交点でぷるっ・合体・乗り移り・落下 |
| `src/stains.js` | 板ににじむ色レイヤー(Canvasテクスチャ) |
| `src/sparkles.js` | きらきら・霧・虹ふぶきパーティクル |
| `src/autoweave.js` | おまかせ織り(かけ算写像→包絡線のお祝い) |
| `src/goals.js` | ゆるい目標とほめことば |
| `src/audio.js` | WebAudio合成効果音+ペンタトニックオルゴール |
| `src/ui.js` / `src/gallery.js` | ひらがなUI・カード保存(localStorage) |

技術: Three.js r185 / WebGL / WebAudio。外部アセットなし(テクスチャ・音はすべて実行時生成)。

`window.__dbg()` で糸・しずく数などの内部状態を確認できます(開発用)。
