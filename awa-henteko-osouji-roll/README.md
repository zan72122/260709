# あわあわ へんてこ おそうじロール 🫧

4さいから あそべる、スフェリコンころがし 3D ゲーム。

**スフェリコン**は、まるくないのに ころころ ころがる ふしぎな かたち。
ころがすと くねくね・よたよた、へんてこな みちすじで すすみます。
その ふしぎな うごきで、あわを おしのけ、よごれを ふきとり、いろを ひろげ、
おはなを さかせる ——「ころがした しゅんかん、せかいが かわる」あそびです。

## あそびかた

- **スワイプ** … ころがしたい ほうこうへ ゆびを すべらせる
- **ロールを タップ** … ぴょん！ と ジャンプ
- **とおくを タップ** … そこへ むかって ころがる

かってな ほうこうに まっすぐ すすまないのが スフェリコンの みそ。
くねくね ゆれながら すすむ きどうを たのしんでください。

## 実行方法

ビルド不要の静的サイトです。フォルダを HTTP サーバで配信して開くだけ：

```bash
cd awa-henteko-osouji-roll
python3 -m http.server 8000
# → http://localhost:8000 を iPhone/iPad の Safari で開く
```

縦画面・横画面どちらでも遊べます。ホーム画面に追加するとフルスクリーンになります。

## 技術メモ

- **Three.js r160**（`vendor/` に同梱、CDN 不要・オフライン動作）
- **スフェリコンの転がりは正確な運動学**で実装しています。接地線（頂点から伸びる斜辺）を軸にした回転で、頂点ピボットを交互に切り替えながら π/√2 ずつ旋回する蛇行軌道・一定重心高 r/√2 を再現。`test/roll-test.mjs` が「表面が常に床に接する（貫通も浮きもしない）」ことを数値検証します
- 床は 104×104 グリッドのセル・シミュレーション（泡の運搬と崩れ、よごれ、水分、絵の具の混色、生長）。2枚の DataTexture 経由でカスタムシェーダが描画
- 泡は InstancedMesh のフレネル虹彩シェーダ、音は全て WebAudio によるプロシージャル合成（コトン・コロンという転がり音は接地面の切り替わりイベントと同期）
- 依存パッケージなし、ビルドなし
