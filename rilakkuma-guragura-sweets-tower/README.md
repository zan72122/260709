# ねらって！とばして！リラックマ ぐらぐらスイーツタワー

くまさんたちと いっしょに、スイーツを とばして たか〜いタワーをつくる 3D ゲームです。
4さいの おこさまが iPhone / iPad(たてがめん・よこがめん どちらでも)で あそぶことを
そうていした、やさしくて にぎやかな パーティーゲームです。

## あそびかた

1. 「▶ あそぶ！」を タップ
2. おさらの うえを うごきまわる **わっか(ねらいマーク)** を よくみて…
3. すきな タイミングで がめんを **タップ！** スプーンの はっしゃだいから スイーツが とんでいくよ
4. まんなかに のると「**ぴったり！**」— れんぞくで きめると コンボで はなびが あがる！
5. はしっこに のると タワーが **ぐらぐら〜！** 「タップして おさえて！」が でたら いっぱい タップ！
6. いちごを 3こ おとしたら おしまい。せいせきと **スイーツずかん** が ひらくよ

## もりもり たのしい要素

- **スイーツ 15しゅるい** — ホットケーキ / ショートケーキ / プリン / マカロン / ドーナツ /
  おだんご / アイス / カップケーキ / ワッフル / チョコ / いちごだいふく / クッキー +
  スペシャル 3しゅ。ぜんぶ プロシージャル生成の 3D モデル(かおつき スイーツも!)
- **スペシャルスイーツ**
  - 🍯 **はちみつポット**(8こごと)… しばらく タワーが ぐらぐらしなくなる
  - 🌈 **にじいろキャンディ**(12こごと)… かならず ぴったり!はなび付き
  - 🥞 **おおきなホットケーキ**(10こごと)… チェックポイント。ここから下は もう くずれない
- **そらの 5フェーズ** — つむほど そらが かわる:あさ → ゆうやけ → よる(ほしぞら)→
  くものうえ → うちゅう
- **ぐらぐらミニゲーム** — タワーが あばれたら れんだで おさえる きんきゅうイベント
- **とりさんレスキュー** — 5こごとに 1かい、はずしても とりさんが キャッチして のせてくれる
- **なかまたち** — くまさん・しろくまさん・とりさんが おうえん(ジャンプ/はくしゅ/びっくり)。
  タップすると てれちゃう ハートつき
- **ぴったりコンボ / マイルストーンはなび / かみふぶき / きらきらトレイル**
- **スイーツずかん** — つんだ スイーツが ずかんに とうろく(localStorage に えいきゅうほぞん)
- **さいこうきろく & ほし3つ ひょうか**、しんきろく演出
- **ぜんぶ WebAudio 合成の BGM(ワルツ)と 20しゅるい以上の SFX**、ミュートボタン
- **バイブレーション**(たいおう端末のみ)、セーフエリア対応、縦横レスポンシブ

## デザインメモ(4さいむけ)

- そうさは「タップだけ」。ドラッグも スワイプも いらない
- 判定は おおあま
  (まんなか 30% は ぴったり / 62% までは のる / はみだしても ふちに くっつく)
- タワーの ずれは じかんと ともに まんなかへ もどる(こっそり おてつだい)
- しっぱいしても おこられない。3かい おとしたら「よくがんばりました!」の おいわい

## 技術

- three.js r160(`vendor/` に同梱、ネットワーク不要)による ニンテンドー3DS風の
  ぽってり かわいい 3D。ソフトシャドウ + ACES トーンマッピング + パステルグラデーションの空
- 物理は 自作の「ゲームらしい」簡易シミュレーション(`src/tower-core.js` は純ロジックで
  node 単体テスト可能)
- 依存パッケージ 0。静的ファイルのみで動作

## 起動

```bash
cd rilakkuma-guragura-sweets-tower
python3 -m http.server 8000
# → http://localhost:8000 を iPhone/iPad/PC のブラウザで開く
```

## テスト

```bash
npm test   # node test/core-test.mjs && node test/smoke.mjs
```

- `test/core-test.mjs` … 着地判定・ぐらぐらバネ・くずれ判定などの純ロジック
- `test/smoke.mjs` … 全モジュール import + タワー30段の end-to-end シミュレーション

## ファイル構成

```
rilakkuma-guragura-sweets-tower/
├── index.html          # 画面・UI・CSS
├── src/
│   ├── main.js         # ゲームループ・状態機械・発射台・カメラ
│   ├── tower.js        # タワー(積み上げ・スウェイ描画・落下物理)
│   ├── tower-core.js   # 純ロジック(判定/バネ/くずれ) — node でテスト可
│   ├── sweets.js       # スイーツ15種のプロシージャル生成
│   ├── characters.js   # くまさん・しろくまさん・とりさん
│   ├── world.js        # 空・雲・テーブル・ガーランド・スカイフェーズ
│   ├── particles.js    # かみふぶき・きらきら・はなび
│   ├── audio.js        # WebAudio 合成 BGM & SFX
│   └── ui.js           # HUD・ポップ・ふきだし・ずかん
├── test/               # node テスト
└── vendor/             # three.module.min.js (r160)
```
