# えがおクエスト 〜とりもどせ！みんなの顔〜

ニンテンドー3DSの『Miitopia（ミートピア）』風の、スマホで遊べる 3D ミニRPG です。
だいまおうに ぬすまれた「みんなの顔」を、自分でつくった なかまたちと取り戻す旅に出よう！

iPhone / iPad の **縦画面・横画面どちらでも** 遊べます。ブラウザだけで動作します（three.js 同梱、外部通信なし）。

## 遊びかた

1. `index.html` をブラウザで開く（ローカルなら `python3 -m http.server` などで配信）
2. 「はじめから」→ **キャラメイク** で勇者と なかま3人の顔・髪型・職業・性格をカスタマイズ（🎲おまかせもOK）
3. マップからルートを選ぶと、パーティが自動で歩いて冒険開始！
4. バトルは勇者だけコマンド操作（たたかう / スキル / おうえん）、なかまは性格に応じて自動で行動
5. 宿屋で休んで、たべもので強化して、だいまおうを倒そう！

## モリモリの楽しい要素

- 😀 **キャラメイク**: 肌色5 × 髪型6 × 髪色8 × 目6 × 眉4 × 口6 の顔エディタ + 名前
- ⚔️ **6つの職業**: せんし / まほうつかい / そうりょ / とうぞく / アイドル / りょうりにん（それぞれ固有スキル3つ、レベルで解放）
- 🤪 **4つの性格**: がんばりや（追撃）/ クール（回避・会心）/ のんき（昼寝で回復）/ おちゃめ（敵を笑わせる）
- 💕 **きずなシステム**: 一緒に戦う・食事・おもちゃで絆レベルUP → 連携攻撃が発生！
- 😶 **顔どろぼう**: モンスターが村人の顔をつけている！ 倒すと顔が空へ帰っていく
- 🗺 **4つのエリア**: そよかぜ草原 / ひざし砂漠 / こごえ雪原 / まおうの城（各3ルート + ボス）
- 🌈 **クリア後のエンドレスダンジョン**「ゆめのとう」（敵がどんどん強くなる、最高記録に挑戦）
- 🎲 **道中イベント**: 宝箱 / いやしの泉 / たべもの拾い / 旅人とジャンケン勝負 / ちょうちょ追いかけ
- 🍖 **たべもの集め**: 7種類の食材でステータス強化（宿屋で食べさせる）
- 🎰 **おもちゃガチャ**: 10Gで回して なかまの絆を深める
- 🍌 **アイテム**: HPバナナ（復活も可）/ MPキャンディ
- 🎯 **敵タップでターゲット選択**、⏩ バトル倍速（x1〜x3）、🤖 オートバトル
- 🎵 **全曲プロシージャル生成のチップチューンBGM**（エリア別5曲 + バトル / ボス / 宿屋）と効果音
- 💾 **セーブ/つづきから**（localStorage）
- ✨ 3Dの見どころ: トゥーンシェーディング、空のグラデーション + 雲 / 星空、花びら / 砂 / 雪 / 星のパーティクル、ダメージポップ、画面シェイク、会心カットイン風エフェクト

## 操作

| 場面 | 操作 |
|---|---|
| 移動中 | 画面タップで主人公がジャンプ（たまに 1G 拾う！） |
| バトル | 下のコマンドボタン / 敵をタップしてターゲット選択 |
| 右上 | 🍌/🍬 アイテム（弱っているなかまに自動で使用） |
| 左中 | オート切替 / 倍速切替 |

## 技術メモ

- three.js r170（`vendor/` に同梱、importmap 使用）、ビルド不要の素の ES Modules
- 顔は Canvas 2D で描画してテクスチャ化（頭部球体 + HUD アイコン + モンスターの盗まれた顔で共用)
- BGM / SFX は WebAudio でリアルタイム合成（音源ファイルなし）
- `viewport-fit=cover` + `env(safe-area-inset-*)` でノッチ対応、縦横両対応レスポンシブ

## フォルダ構成

```
egao-quest/
├── index.html      # UI / CSS / DOM
├── vendor/         # three.js
└── src/
    ├── main.js     # 起動・ゲームフロー・レンダラ
    ├── data.js     # 職業・性格・敵・エリア・たべもの等のデータ
    ├── state.js    # パーティ・きずな・セーブ
    ├── mii.js      # Mii風キャラ生成（顔テクスチャ・髪型・武器・アニメ）
    ├── monsters.js # モンスター生成（盗まれた顔つき）
    ├── scenes.js   # 空・地形・小物・パーティクル
    ├── maker.js    # キャラメイク画面
    ├── map.js      # ぼうけんマップ
    ├── walk.js     # 自動歩行ルート＆道中イベント
    ├── battle.js   # ターン制バトル
    ├── inn.js      # 宿屋
    ├── ui.js       # HUD・ダイアログ・3Dポップアップ
    └── audio.js    # プロシージャルBGM/SFX
```
