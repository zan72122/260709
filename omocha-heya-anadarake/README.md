# おもちゃのへや あなだらけ!

Donut County 風の「穴」サンドボックス 3D ゲーム。
おもちゃの部屋の床にあいた小さな穴を指で動かして、クレヨンから積み木、
ぬいぐるみ、三輪車、最後はベッドまで、部屋じゅうを丸ごと吸い込みます。

4歳児(文字が読めない前提)が iPhone / iPad の Safari で、縦画面でも
横画面でも遊べるように作っています。UI はぜんぶアイコン、失敗も時間制限も
ありません。

## あそびかた

- **タップ / なぞる** … タップした場所に穴がすーっと移動します
- 穴より小さいモノは **ストン** と落ち、穴が少し大きくなります
- ぜんぶ吸い込むと大きなお祝い → 色や雰囲気が変わった部屋でもう一周
  (ひだまり → ゆうやけ → よぞら の3パレットが循環)

### 起動

```
cd omocha-heya-anadarake
python3 -m http.server 8000
# → http://localhost:8000 を Safari / Chrome で開く
```

ビルド不要・外部アセットなし(Three.js は vendor/ に同梱、音は WebAudio 合成)。

## こだわりの落下描写

穴とモノの関係は汎用物理エンジンではなく、`src/physics.js` の
穴専用ステートマシンで 1 つずつ演出として作り込んでいます。

| ふるまい | 条件 | 見た目 |
| --- | --- | --- |
| ストン | 穴がモノよりはっきり大きい | まっすぐ気持ちよく落ちる(軽く伸びる) |
| ころころ | 丸いモノが縁にかかる | 箱より早く転がり込む |
| ぐらぐら | 一部だけ縁に乗る | 穴側に傾いて揺れ、穴が離れるとぷるんと戻る |
| するっ | 細長いモノ(クレヨン・棚・ベッド) | 縦に起き上がって長さ方向に滑り込む |
| ぎゅっ | 大きさが穴とほぼ同じ | 口に挟まってグラグラ → ぽんっと通るか、弾き出される |
| ガタガタ | 車体は入らないが車輪が穴の上 | 車輪だけ落ちて傾き、ガタガタ鳴る(三輪車・汽車・ワゴン) |
| 橋渡し | モノが穴よりずっと大きい | 穴をまたいで少したわむ |

### ギミック

- **ロケット発射** 🚀 … 吸い込んだモノを打ち上げて、着地の衝撃波で
  棚の上のモノを落としたり、風船を割ったりできる
- **おふろの水** … 浴槽を吸うと穴に水がたまり、アヒルやボートが
  ぷかぷか浮いてから ごぼごぼ沈む
- **風船のプレゼント** … 穴では吸えない。発射でパンと割るか、
  大きくなった穴でじっと待つと風船がすっぽ抜けて落ちてくる
- **積み上げ・棚の上** … 土台を吸うと上のモノが飛び散って床に落ちる

## 構成

```
index.html        iOS 向けシェル(タッチ制御・アイコンUI・お祝い画面)
src/physics.js    穴専用の自作物理(THREE 非依存・node でテスト可能)
src/props.js      プロシージャルなおもちゃ 48 個 + 部屋レイアウト + 3 パレット
src/hole.js       床シェーダーの穴あけ・内壁・リム・水面
src/room.js       床・壁・窓・照明(ラウンドごとに再構築)
src/effects.js    キラキラ・土煙・水しぶき・衝撃波リング・紙吹雪
src/audio.js      WebAudio 合成の BGM + 効果音(落下音はモノの大きさで音程が変わる)
src/ui.js         アイコンだけの DOM UI
src/main.js       ループ・入力・カメラ(縦横対応)・イベント→演出の接続
test/             物理ユニットテスト + ボットが部屋を完食する通しスモーク
```

### テスト

```
npm test
```

- `physics-test.mjs` … ストン/ころころ/ぐらぐら/するっ/ぎゅっ/ガタガタ/
  橋渡し/積み木/発射/風船/水 の全遷移を検証
- `smoke.mjs` … 実レイアウトをヘッドレスで読み込み、ボットが 48 個
  すべて吸い込んでクリアできること(進行が詰まないこと)を検証
