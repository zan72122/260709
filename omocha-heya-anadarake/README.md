# おもちゃのへや あなだらけ!

Donut County 風の「穴」サンドボックス 3D ゲーム。
おもちゃの部屋の床にあいた小さな穴を指で動かして、クレヨンから積み木タワー、
ぬいぐるみ、三輪車、最後は2段ベッドまで、部屋じゅうを丸ごと落とし込みます。

4歳児(文字が読めない前提)が iPhone / iPad の Safari で、縦画面でも
横画面でも遊べるように作っています。UI はぜんぶアイコン、失敗も時間制限も
ありません。

## あそびかた

- **タップ / なぞる** … タップした場所に穴がすーっと移動します
- 支えを失ったモノは**縁からゴロンと転がり落ちます**(吸い込みません)
- ぜんぶ落とすと大きなお祝い → 色や雰囲気が変わった部屋でもう一周
  (ひだまり → ゆうやけ → よぞら の3パレットが循環)

### 起動

```
cd omocha-heya-anadarake
python3 -m http.server 8000
# → http://localhost:8000 を Safari / Chrome で開く
```

ビルド不要・外部アセットなし(Three.js は vendor/ に同梱、音は WebAudio 合成)。

## 「吸う」ではなく「落ちる」— 重力主体の穴物理

穴とモノの関係は汎用エンジンではなく `src/physics.js` の穴専用
ステートマシンです。v2 では水平方向の引き寄せを全廃し、
**すべての落下が「支えの喪失」と「縁(リム)」から始まります**。

| ふるまい | 条件 | 見た目 |
| --- | --- | --- |
| ストン | 足元がまるごと穴の上 | 自由落下でまっすぐ落ちる |
| ゴロン | 重心は穴の上・片側はまだ縁の上 | 縁を支点に倒れ込んで転がり落ちる |
| コツン | 落下中 | 穴の内壁にぶつかって跳ね、回転しながら落ちていく |
| するっ | 細長いモノの**片端**が穴の上 | その端から突っ込んで縦に滑り込む |
| 橋渡し | 細長いモノの**真ん中**だけ穴の上 | 両端が支えるので落ちずにたわむ(端を狙えば落ちる) |
| ぐらぐら | 一部だけ縁に乗る | 傾いて揺れ、穴が離れるとぷるんと戻る |
| ぎゅっ | 大きさが穴とほぼ同じ | 口に挟まって→ぽんっと通るか、弾き出される |
| ガタガタ | 車体は入らないが車輪が穴の上 | 車輪だけ落ちて傾き、ガタガタ鳴る |

視点は斜め(仰角40°)で、全モノに接地影(ブロブシャドウ)。
浮いているのか、置いてあるのか、落ちたのかが一目で判ります。

## 部屋のしかけ

- **揺すり落とし** … 棚・机・壁掛け棚(備え付けで吸えない)の下に穴を
  置くとガタガタ揺れて、上のおもちゃが少しずつ縁へずれ→ポロッと床へ。
  「落としてから、あらためて穴へ」の2段階遊び
- **積み木タワー** … 5段・4段のタワー。土台を落とすと上がバラバラと
  雪崩れて飛び散る
- **ピニャータおもちゃ箱** … 落とすと中からキャンディやミニおもちゃが
  9個飛び出すジャックポット
- **逃げるゼンマイひよこ親子** … 親どり1羽+ヒヨコ3羽が部屋をトコトコ散歩。
  穴が近づくとピヨピヨ慌てて逃げる。追い詰めて捕まえるとお祝い
- **ロケット発射** 🚀 … 落としたモノを打ち上げ、着地の衝撃で棚のモノを
  落としたり風船を割ったりできる
- **おふろの水** … 浴槽を落とすと穴に水がたまり、アヒルが浮いてから沈む
- **風船のプレゼント** … 発射で割るか、大きな穴でじっと待つと風船が抜ける
- **目と表情** … アヒル・くま・木馬・ひよこ達は、穴が近づくと目が点になって
  ビクビク、落ちるときはぎゅっと目をつぶる

## 構成

```
index.html        iOS 向けシェル(タッチ制御・アイコンUI・お祝い画面)
src/physics.js    穴専用の重力物理(THREE 非依存・node でテスト可能)
src/props.js      プロシージャルなおもちゃ 60+ 個・表情・レイアウト・3 パレット
src/hole.js       床シェーダーの穴あけ・内壁・リム・水面
src/room.js       床・壁・窓・照明(ラウンドごとに再構築)
src/effects.js    キラキラ・土煙・水しぶき・衝撃波リング・紙吹雪
src/audio.js      WebAudio 合成の BGM + 効果音(大きさで音程が変わる落下音、内壁のコツン等)
src/ui.js         アイコンだけの DOM UI
src/main.js       ループ・入力・カメラ(縦横対応)・接地影・表情・イベント→演出
test/             物理ユニットテスト + ボットが部屋を完食する通しスモーク
```

### テスト

```
npm test
```

- `physics-test.mjs` … 吸引ゼロ回帰(縁のモノが横に動かないこと)を筆頭に、
  ストン/ゴロン/コツン/するっ/正直な橋渡し/ぎゅっ/ぽんっ/ガタガタ/
  タワー雪崩/揺すり落とし/ピニャータ/ひよこ追跡/風船/水 を検証
- `smoke.mjs` … 実レイアウトをヘッドレスで読み込み、ボットが端狙い・
  揺すり・追いかけも使って全部(ピニャータの中身込み)落とし切れることを検証
