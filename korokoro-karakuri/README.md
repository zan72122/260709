# 🎡 コロコロからくり (korokoro-karakuri)

Automatoys にインスパイアされた、木のおもちゃ風の 3D からくり装置ゲーム。
4歳児が iPhone / iPad(縦画面・横画面どちらでも)で遊ぶことを想定しています。

たった1個の玉を、タップとながおしで装置のてっぺんからゴールの鐘まで運びます。
衝突音はすべてペンタトニック音階に量子化されるので、**遊ぶだけで音楽になります**。

## あそびかた

1つの超大作からくり装置を、玉が上から下へ旅します。

| からくり | そうさ | うごき |
|---|---|---|
| スタートハンドル | タップ | ホッパーが傾いて玉が転がり出す |
| シーソー | タップ | 傾きが反転して玉を右へ送る |
| ペグ落下路 | (自動) | カラン、コロンと鳴りながら落ちる |
| 水車 | タップ | 90°ずつ回転。ポケットが玉をすくって持ち上げる |
| エレベーター | ながおし | 押している間だけ上昇。てっぺんで玉を送り出す |
| スイッチ | タップ | 分岐を切替。ループ側だと玉はエレベーターに戻ってくる |
| ワイヤースライド | (自動) | リングをくぐって前面レイヤーを滑り降りる |
| カタパルト | ながおし→はなす | ぎゅ〜っとチャージして、リングをくぐってゴールへ発射! |
| ゴールの鐘 | — | チリンチリン♪ 紙吹雪とファンファーレでお祝い |

- **ガイド ON/OFF**: ONにすると、次に操作する場所に**3Dの手**が現れて、タップ/ながおしの動きをお手本で見せてくれます(ふきだしはすべてひらがな)。
- **おと**: ミュート切替。
- **たまを もどす**: 玉をホッパーに戻します。
- 落ちた玉・詰まった玉は自動でホッパーに戻ります(ポフッ)。

## 実行方法

```bash
cd korokoro-karakuri
npm start        # python3 -m http.server 8000
# → http://localhost:8000 を iPhone/iPad の Safari か PC ブラウザで開く
```

外部CDN・外部アセットは一切使いません(Three.js はローカル同梱、テクスチャ・音はすべてコード生成)。

## テスト

```bash
npm test
```

- `test/layout.test.mjs` — 装置の接続整合性(各からくりの受け渡し位置・隙間・クリアランスが玉のサイズに対して正しいか)
- `test/physics.test.mjs` — 自作物理(静止・坂・貫通なし・ペグ反発・動く床・z復元)
- `test/audio.test.mjs` — 衝突音のペンタトニック量子化
- `test/smoke.mjs` — 全モジュールの構文チェックと import

さらに開発時は Playwright + ヘッドレス Chromium で、
「ハンドル→シーソー→水車→エレベーター→スイッチ→スライド→カタパルト→ゴール→リスポーン」
の全行程と、スイッチのループ経路を実プレイして検証しています。

## 技術メモ

- **Three.js r160**(`vendor/three.module.min.js` に同梱)+ **自作の決定論的な球物理**
  (球 vs 有向ボックス / Z軸円柱、240Hz固定サブステップ、キネマティック部品は表面速度を供給)
- 木目・塗装・ペグボード・背景はすべて **Canvas でプロシージャル生成**
- ACES トーンマッピング、PCF ソフトシャドウ、縦横比に応じた自動カメラフレーミング+玉へのゆるやか追従
- 音は **WebAudio 全生成**: マリンバ音色、鐘(FM)、木のカタン、チャージ音、ファンファーレ
- 玉の受け渡しは「物理」と「スクリプトライド(捕捉→曲線移動)」のハイブリッドで、
  4歳児でも絶対に詰まない・必ずゴールできる寛容さを優先

## 構成

```
korokoro-karakuri/
├── index.html        # UI(タイトル・HUD・ふきだし・バナー)
├── src/
│   ├── layout.js     # 装置全体の寸法・配置(純データ、テスト対象)
│   ├── physics.js    # 自作物理エンジン
│   ├── materials.js  # プロシージャル木目・テクスチャ
│   ├── machine.js    # 静的構造(土台・背板・レール・ゴール・飾り)
│   ├── gimmicks.js   # 可動ギミック8種
│   ├── ball.js       # 玉(物理/捕捉/ライドの3モード)
│   ├── guide.js      # 3Dの手のガイド
│   ├── audio.js      # WebAudio 音楽エンジン
│   ├── particles.js  # 紙吹雪・木くず・埃の光
│   ├── camera.js     # 縦横対応の自動フレーミング
│   ├── input.js      # タッチ入力(大きな当たり判定)
│   ├── ui.js         # DOM UI
│   └── main.js       # 統合・ゲームループ
├── vendor/three.module.min.js
└── test/
```
