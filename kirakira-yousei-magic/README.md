# キラキラ☆ようせいマジック にじいろガーデン 🧚🌈

リルリルフェアリル風の、おはなの ようせいと あそぶ 3D まほうガーデン。
**4歳児が iPhone / iPad で遊ぶこと**を想定した、タップだけで遊べる
「まけない・こまらない」ゲームです。縦画面・横画面どちらも対応。

## あそびかた

1. **▶ はじめる** をタップ
2. すきな ようせいを タッチしてえらぶ(5にん から えらべるよ)
3. がめんを タップすると ようせいが とんでいく ✨
4. **キラキラひかる つぼみ**の ちかくへ とぶと、おはなが さく 🌸
5. おはなを たくさん さかせると **まほうのカギ** が でてくる 🗝️
6. カギを とって **とびら**へ いくと…にじいろポータルが ひらいて つぎのせかいへ!
7. とびらの むこうから **なかま**が やってきて、パレードが どんどん にぎやかに 💖

### 4つの せかい

| ステージ | テーマ | なかま |
|---|---|---|
| 🌷 おはなの ガーデン | ひるの おはなばたけ | ちょうちょの ペアリル |
| 🍄 ひかる キノコの もり | ゆうやけ + ひかるキノコ + ホタル | ふわふわ うさリル |
| ⭐ おほしさまの そら | よぞら + うかぶしま + ながれぼし | ほしのこ キララ |
| 🌈 にじいろの おしろ | にじの アーチ + パステルの おしろ | にじいろ ことリル |

ぜんぶ クリアすると **はなび パーティー** モード! タップするたび はなびが あがるよ 🎆

## モリモリの たのしい要素

- **タップ** — ようせいが とんでいく + キラキラ + ペンタトニックの チャイム(なにを おしても きれいな メロディーになる)
- **つぼみ** — ちかくを とぶだけで さく(ちいさなゆびでも だいじょうぶ)
- **さいた おはな** — タッチすると ぷるんと はねて おとが なる(おはなの がっき)
- **ゆびで なぞる** — にじいろの ほしくずが ゆびに ついてくる 🪄
- **ながおし** — ようせいの まわりに にじの らせんまほう + ハープのグリッサンド
- **なかま** — タッチすると ぷるん! と よろこぶ。ようせいのうしろを パレードする
- **⭐ジェム** — おはなから とびだして ようせいに あつまる。12こ ごとに ボーナスはなび
- **🎀ボタン** — ドレスの いろが くるくる かわる(7しょく)
- **ながれぼし・ホタル・うかぶしま・ながれるくも** — せかいが いきている
- **ほめことば** — 「すごーい!」「ピッカピカ!」が ポンポン でてくる
- **なにも しなくても** — ようせいが くるっと まわって さそってくれる
- まけ・しっぱい・じかんせいげん は **いっさい なし**

## 技術メモ

- Three.js r160(`vendor/` に同梱、ネットワーク不要・完全オフライン動作)
- ジオメトリ/テクスチャ/効果音/BGM すべてプロシージャル生成(外部アセット 0)
- シェーダー製グラデーション空(太陽グロー + またたく星)、ACES トーンマッピング
- GPU ポイントスプライト 2200 発のパーティクルプール(バースト/軌跡/花火/スパイラル/レイン共用)
- WebAudio 生成音: オルゴール風 BGM(ステージごとに転調)、ペンタトニック チャイム、ファンファーレ
- iOS 対応: `viewport-fit=cover` + safe-area、タッチで AudioContext アンロック、`devicePixelRatio` 上限 2、縦横両対応カメラ

## 実行

```bash
npm start   # python3 -m http.server 8000
# → http://localhost:8000 を iPhone/iPad の Safari か PC ブラウザで開く
```

## テスト

```bash
npm test    # node test/smoke.mjs — データ整合性 + 進行ロジックの一気通貫テスト
```
