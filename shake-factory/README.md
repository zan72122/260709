# まっすぐシャカシャカ ふりわけ工場 🏭✨

4さいから あそべる、さわると すぐ うごく 3D ぶつり じっけん ゲーム。

**くるくる まわすと、なぜか まっすぐ シャカシャカ うごく！**

丸いハンドルをくるくる回すと、大きな輪の中で小さな円がころころ転がり
（トゥースィー・カップル機構）、真ん中のノズルが**一直線に左右へ往復**します。
ノズルからビー玉とシロップが落ちてきて、左右の透明カップに色がたまり、
しましま模様になり、あふれるとゼリーの池ができて泡がぷくぷく…！

## あそびかた

| そうさ | なにが おこる |
|---|---|
| 丸いハンドルをくるくる回す | ノズルがまっすぐシャカシャカ動いて、ビー玉とシロップが降る |
| はやく回す | ビー玉がびゅーんと飛ぶ！ |
| ゆっくり回す | ねらったカップにきれいに入る |
| ハンドルを逆回しでシャカシャカ | シャカシャカボーナス！ビー玉がおまけで出る |
| カップをドラッグ | カップを左右に動かせる（2本指で ハンドル＋カップ同時もOK） |
| 下の色ボタン | シロップの味（色）を変える |
| 🫧 ボタン | ぜんぶピカピカにおそうじ |

いっぱいになるとあふれて、床にゼリーの池が広がります。
3色以上こぼすと **にじいろの池** に！

小さなミッション（しましまカップを作ろう！など）をクリアすると ⭐ がもらえます。
勝ち負けはありません。ずっと遊べます。

## 動かしかた

ES Modules を使っているので、静的サーバーで配信してください:

```bash
cd shake-factory
python3 -m http.server 8000
# → http://localhost:8000 を iPhone / iPad / PC のブラウザで開く
```

GitHub Pages でもそのまま動きます。縦画面・横画面どちらでも遊べます。
音は最初のタップのあとに鳴り始めます（iOS の仕様）。

## 技術メモ

- Three.js (vendored, `vendor/three.module.min.js`) — 外部CDN・ネット接続不要
- 効果音はすべて WebAudio でリアルタイム合成（音声ファイルなし）
- ビー玉は自前の 2.5D 物理エンジン（球 vs カプセル・球 vs 球）
- カップの液体はカスタムシェーダーで、注いだ層がそのまま「しましま」として残る
- トゥースィー・カップル: 半径 R の円の内側を半径 R/2 の円が転がると、
  円周上の1点は直線を描く — この動きがそのままノズルの駆動になっている

## フォルダ構成

```
shake-factory/
├── index.html      # 画面・UI・スタイル
├── vendor/         # three.js
└── src/
    ├── main.js     # ゲームループ・全体の配線
    ├── world.js    # レンダラー・ライト・背景・床
    ├── machine.js  # 工場本体とトゥースィー機構・ノズル・ホッパー・チューブ
    ├── handle.js   # くるくるハンドル（画面隅の専用ビューポート）
    ├── marbles.js  # ビー玉と物理エンジン
    ├── cups.js     # ガラスカップ・しましま液体・あふれ
    ├── pond.js     # ゼリー池と泡
    ├── fx.js       # しずく・キラキラ・紙ふぶき
    ├── audio.js    # 効果音シンセ
    ├── goals.js    # ちいさなミッション
    ├── ui.js       # HTMLオーバーレイ
    ├── input.js    # マルチタッチ操作
    └── colors.js   # 味（色）の定義
```
